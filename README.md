# Brightside Studio — Business Website

A responsive multi-section business website starter template.

## Files
- `index.html` — page content and semantic structure
- `css/styles.css` — responsive styling and layout
- `js/main.js` — mobile navigation, FAQ accordion, current year, and demo form validation
- `assets/favicon.svg` — browser tab icon

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Before publishing
- Replace the demo brand name, sample projects, testimonial, statistics, email address, business hours, and social links.
- Connect the contact form to a real form provider or server endpoint. It currently validates in the browser only and does not send or store submissions.
- Add your privacy policy, cookie notice if applicable, and any legal/business details required in your location.
- Upload the full folder while preserving the `css`, `js`, and `assets` subfolders.

This is a general-purpose business studio template; adapt the wording and services to your own business.
